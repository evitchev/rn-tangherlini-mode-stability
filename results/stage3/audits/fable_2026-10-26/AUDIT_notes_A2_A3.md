## A2 (Proposition 3 at general n; R for 0 < q < 1; the zeta-design branch)
Sources: results/p3/METHOD.md, METHOD_ADDENDUM_1.md §1, METHOD_ADDENDUM_2.md.
Lemma 1 re-derived: |phi' + S phi|^2 = |phi'|^2 + S (|phi|^2)' + S^2 |phi|^2 (S real); integration by parts with compact support; identity exact. Needs only S in C^1(R) real and V continuous.
Lemma 2 re-derived: dz/drho = 1/rho^2 = (1 - z)^2; d/dr* = f d/drho; S = -f beta; S' = -f(f' beta + f beta'); S^2 = f^2 beta^2; so V~ = f[W - f' beta - f(beta' + beta^2)]. With f' = (1 - z)^2 f_z, beta = (1 - z)P, beta' = (1 - z)^2(-P + (1 - z)P_z) and rho^2 (1 - z)^2 = 1: rho^2 f' beta = (1 - z) f_z P; rho^2 f beta' = f(-P + (1 - z)P_z); rho^2 f beta^2 = f P^2; rho^2 W = U_-/(64 H_-^2). Hence V~ = f N/(64 rho^2 H_-^2) with N as written. No step uses n. Checked endpoint remark: N(1) = U_-(0) - 64 m^2 (P(1)^2 - P(1)) = 64 m^2 (m + 6 - P(1)^2 + P(1)) at n = 4 (U_-(0) = 64 m^3 + 16 n(n+2) m^2 = 64 m^3 + 384 m^2); for l = 2 (m = 6) positive iff -3 < P(1) < 4. Matches.
R for 0 < q < 1, general n: f = 1 - x + q^2 x^2/4 = (1 - x/x_H)(1 - x/x_-) (roots 2/(1 -+ w), w = sqrt(1 - q^2), x_H x_- = 4/q^2); x = x_H (1 - z)^(n-1) in units r_H = 1 (x_H = 2M); so f = (1 - y)(1 - k y), y = rho^(1-n) in (0, 1), k = x_H/x_- = (1 - w)/(1 + w) in [0, 1) for q in [0, 1). f > 0 and C^infinity on (1, infinity); r*(rho) = int drho/f strictly increasing with derivative 1/f > 0, so its inverse R is C^infinity (inverse function theorem, derivative f(R) != 0). Onto R: at infinity 1/f -> 1, divergent integral; at the horizon f = (n - 1)(1 - k)(rho - 1) + O((rho - 1)^2), a simple zero (f_z(0) = (n - 1)(1 - k) > 0 checked), so the integral diverges logarithmically. At q = 1 (k = 1) the zero is double, f ~ (n - 1)^2 (rho - 1)^2, divergence like 1/(rho - 1) (coefficient 1/9 at n = 4 = TARGET_A2 E2). SOUND.
Step 3 of addendum 2 (S in C^1(R)): z o R maps R into (0, 1) smoothly; P in C^1 there; so S is C^1 in r*. Correct, and it uses only P on (0, 1): the hypothesis "C^1 on an open interval containing [0, 1]" is stronger than the proof needs. Relevant to A3 (see below).
Step 5: H_- = m + n(n+1)(1 + m delta) x/2 >= m > 0 needs delta >= 0, which the branch 1 + 2 m delta > 0 gives ((1 + 2 m delta)^2 >= 1). Fine.
Zeta-design branch: P = P^/(z + delta_b)^d, delta_b > 0 rational: C^infinity on (-delta_b, infinity) containing [0, 1]; the pole is outside. N contains P, P_z, P^2 with denominators (z + delta_b)^d, ^(d+1), ^(2d); since 2d >= d + 1 for d >= 1, (z + delta_b)^(2d) N is a polynomial (the addendum does not say why; a one-clause remark). The certificate's N L (z + delta_b)^(2d) > 0 with L > 0 and (z + delta_b)^(2d) > 0 gives N > 0 on [0, 1], more than Proposition 3 asks. SOUND.
Notation remark: addendum 2 writes w = sqrt(1 - q^2) while TARGET_HD §1 uses w = B mu/A (the same quantity by PARAM, w^2 = 1 - q^2), fine; k here is the ratio x_H/x_- and in METHOD_ADDENDUM_1 the same ratio appears as kappa^3 (n = 4). Consistent.
Verdict: SOUND. Hypotheses assumed: S5's reduction and transcription (trust base, addendum 1 §3); the Lean statements are read, not re-checked.

## A3 (the singular-design reduction and its charts)
Sources: TARGET_A2_ADDENDUM_1.md §3, results/a2/s/PREREG.md; TARGET_HD_ADDENDUM_2.md §3, results/hdx/s/PREREG.md.
Pole ansatz re-derived at general n, q = 1: f = (1 - (1 - z)^(n-1))^2 = (n - 1)^2 z^2 + O(z^3), f_z = 2 (n - 1)^2 z + O(z^2); with P = a/z + p (p C^1 at 0) the bracket (1 - z) f_z P + f(-P + (1 - z) P_z + P^2) at z = 0 equals 2(n - 1)^2 a - (n - 1)^2 a + (n - 1)^2 a^2 = (n - 1)^2 a(a + 1). So N(0) = U_-(2) - 64 (n - 1)^2 H_-(2)^2 a(a + 1) = 64 (n - 1)^2 H_-(2)^2 (c - a(a + 1)), c = U_-(2)/(64 (n - 1)^2 H_-(2)^2) (= E3's c at n = 4, 576 = 64*9). Window c - a(a + 1) > 0: a in (-1/2 - nu, -1/2 + nu), nu = sqrt(c + 1/4); with c = l(l - n + 1)/(n - 1)^2: nu = |2l - n + 1|/(2(n - 1)) and for 2l > n - 1 the window is (-l/(n - 1), (l - n + 1)/(n - 1)); n = 4, l = 2: (-2/3, -1/3). Throat slack (n - 1)^2 (c - a(a + 1)) = theta(1 - theta)(2l - n + 1)^2 for a = a_pr + theta(a_ot - a_pr); a = -2/5 is theta = 1/5, slack 4/25 = beta_0. All match the files.
Pole position: eps = w/((n - 1)(1 + w)) = B mu/((n - 1)(A + B mu)) (TARGET_HD §1's w = B mu/A); n = 4, l = 2: 7 mu/(3(6 + 7 mu + mu^2)) = A2-S's eps_n/eps_d. eps_n = B mu >= 0, zero only at mu = 0; eps_d = (n - 1)(A + B mu) > 0 for mu >= 0. The inner horizon: z_- = 1 - k^(-1/(n-1)) ~ -delta_t/(n - 1) with delta_t = 1 - k = 2w/(1 + w), and eps = delta_t/(2(n - 1)): the throat's centre, as stated.
(i) Smoothness of S: for mu > 0 the pole z = -eps < 0 is outside [0, 1], P is C^infinity on (-eps, infinity), S = -f(1 - z)P is C^infinity on the exterior and Proposition 3 (addendum 2's form) applies. For mu = 0 (q = 1) eps = 0 and the pole is AT z = 0, the horizon: outside the open exterior (0, 1) but not outside [0, 1]. The brief's and TARGET_A2_ADDENDUM_1's phrase "outside [0, 1]" / "z = -eps <= 0 lies outside (0, 1)": the second is the correct one. At mu = 0 the pencil statement of METHOD_ADDENDUM_2 (P C^1 on an open interval containing [0, 1]) does not apply as written; the files cite Lean's prop3_Ioo (P C^1 on (0, 1)) for exactly this. The pencil proof of addendum 2 goes through unchanged under the weaker hypothesis: its step 3 uses only z(rho) in (0, 1), and Lemma 1 needs S in C^1(R), which holds since z o R lands in (0, 1). So the reduction is sound at every mu in [0, mu_1]; what is missing is a one-line restatement of the pencil Proposition with hypothesis "P in C^1(0, 1)" (addendum 2's last paragraph argues it in words). GAP-MINOR (wording), fix: restate.
Also at mu = 0: f P ~ (n - 1)^2 z^2 * a/z -> 0, so S is even bounded; not needed.
(ii) Cover: rectangle (0, 1) x [0, mu_1], charts O [z_1, 1] x [0, mu_1]; O' [0, z_1] x [mu_T, mu_1]; T: z = mu zeta, (zeta, mu) in [0, Z_T] x [0, mu_T]; C: mu = z sigma, (z, sigma) in [0, z_1] x [0, sigma_1]; z_1 = 1/4, Z_T = 8, mu_T = 1/32, sigma_1 = 1/8, mu_1 = 1/8. Case split: z >= z_1 -> O (needs z_1 <= 1). z < z_1, mu >= mu_T -> O' (needs mu_T <= mu_1). z < z_1, mu < mu_T: if z <= Z_T mu then mu >= z/Z_T > 0, zeta = z/mu in (0, Z_T], (zeta, mu) in T's box, and NL(z, mu) = mu^2 T(zeta, mu) > 0 by DIV-T and POS-T; else z > Z_T mu, sigma = mu/z < 1/Z_T <= sigma_1 (this is Z_T sigma_1 >= 1), (z, sigma) in C's box, NL = z^2 C(z, sigma) > 0 by DIV-C and POS-C (mu = 0 included, sigma = 0). So every point of (0, 1) x [0, mu_1] has a chart with NL > 0; with S > 0 (z > 0, eps_n >= 0, eps_d > 0) and L > 0 (gates S, L), N = NL/(S^2 L) > 0. SOUND.
